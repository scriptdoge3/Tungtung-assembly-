About

Tungtung Assembly is an experiment in radical minimalism: a website with no runtime dependencies at all.

What is NOT here

  • No JavaScript or TypeScript — not one byte
  • No CSS — your browser's default styles are doing all the work
  • No JSON — the only data format is HTML itself
  • No HTTP library or web framework — requests are parsed with byte compares and responses are assembled with sendto(2) calls
  • No libc — the binary is freestanding and talks to the kernel directly

What IS here

  • One assembly source file: server.s
  • Four HTML files, baked into the binary at build time with .incbin
  • A shell script that runs as and ld
