=============================================================================
  ABOUT                                                  tungtung-asm-httpd
=============================================================================

 Tungtung Assembly is an experiment in radical minimalism: a website with
 no runtime dependencies and no markup of any kind.

 WHAT IS NOT HERE
 ----------------
   * no HTML       -- pages are text/plain; your browser renders raw bytes
   * no CSS        -- the "design" is whitespace and ASCII box art
   * no JavaScript, no TypeScript -- not one byte
   * no JSON       -- the only data format is text itself
   * no HTTP library or framework -- requests are parsed with byte
                      compares, responses assembled with sendto(2)
   * no libc       -- the binary is freestanding; it talks straight
                      to the kernel

 WHAT IS HERE
 ------------
   * one assembly source file:  server.s
   * four .txt files, baked into the binary at build time with .incbin
   * a shell script that runs `as` and `ld`. that is the build system.
