                          A S S E M B L Y

=============================================================================

 You are looking at a website served over real HTTP by a server written
 ENTIRELY in x86-64 assembly.

 There is:

    [x] no HTML        (this is text/plain, straight from the socket)
    [x] no CSS         (what you see is what there is)
    [x] no JavaScript  (view-source and weep: it's identical)
    [x] no TypeScript
    [x] no JSON
    [x] no HTTP library, no framework, no libc

 Just raw Linux syscalls, hand-parsed requests, hand-written responses.

 THE ENTIRE STACK

     your browser (or curl)
           |
           |  TCP :8080
           v
     +------------------+
     |  server  (ELF)   |    a tiny static binary
     |                  |
     |   socket(2)      |
     |   bind(2)        |
     |   listen(2)      |
     |   accept(2)      |
     |   read(2)        |  <- parses "GET /path HTTP/1.1" by hand
     |   sendto(2)      |  <- writes status line, headers, body by hand
     |   close(2)       |
     +------------------+
           |
           v
     the Linux kernel. that's it. there is nothing else.
